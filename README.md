# vpnroute

Точечная маршрутизация для OpenWrt: трафик к доменам и IP из списков идёт через VPN-туннель (Xray, VLESS), остальной — напрямую. Отдельные устройства можно целиком пустить через VPN одной кнопкой.

Работает на Xiaomi AX3000T с OpenWrt 25.12.6 и Xray 26.3.27 (роутер `192.168.2.1`). Должно работать и на других роутерах с OpenWrt 24.10+, но проверено только на этом.

Текущее состояние и что осталось проверить — [docs/plan.md](docs/plan.md).

## Возможности

- VPN-клиент **Xray**: VLESS с транспортами tcp, ws, grpc, httpupgrade, **xhttp** и защитой tls/reality. Сервер добавляется ссылкой `vless://…`.
- Несколько серверов: используется самый быстрый из доступных. Если недоступны все — трафик идёт напрямую (отключаемо).
- Списки доменов и IP/подсетей **в панели LuCI**: несколько списков, каждый включается отдельно, запись `example.com` покрывает все поддомены.
- **DNS для доменов из списков не уходит к провайдеру**: роутер сразу отвечает служебным адресом, а настоящий адрес узнаёт VPN-сервер. Подмена и вырезание записей у провайдера не мешают.
- Устройства «весь трафик через VPN» с переключением кнопкой на странице «Состояние» или командой `vpnroute device <имя> toggle`.
- Защита от обхода: перехват DNS, блокировка DoT и известных DoH-серверов, блокировка IPv6.
- Проверка «куда пойдёт этот домен» из панели и командной строки.
- **Диагностика трафика устройства**: запись всех соединений и DNS-запросов одного устройства, статусы вроде «нет ответа» или «сброс», фильтры и добавление найденного в список VPN одной кнопкой ([docs/trace.md](docs/trace.md)).

## Установка

Нужен доступ к роутеру по SSH по ключу (LuCI → Система → Администрирование → SSH-ключи).

С ПК под Windows:

```powershell
.\scripts\deploy.ps1 -Router 192.168.2.1            # первая установка, с пакетами
.\scripts\deploy.ps1 -Router 192.168.2.1 -NoDeps    # обновление файлов после правок в репозитории
```

Из Linux, macOS или Git Bash:

```sh
./scripts/deploy.sh 192.168.2.1
```

Скрипт копирует репозиторий в `/tmp/vpnroute` на роутере и запускает [scripts/install.sh](scripts/install.sh). Установщик:

1. ставит пакеты `xray-core kmod-nft-tproxy ip-full ucode ucode-mod-uci ucode-mod-fs` (через apk или opkg);
2. копирует файлы, **не перезаписывая** существующий `/etc/config/vpnroute`;
3. подключает к dnsmasq файл `/etc/vpnroute/dnsmasq.servers`;
4. включает службу `vpnroute`.

Повторный запуск безопасен: существующие настройки `/etc/config/vpnroute` не перезаписываются.

## Первые шаги после установки

**LuCI → Службы → VPN-маршрутизация → Настройки:**

1. **Серверы** → «Добавить» → вставить ссылку `vless://…` из панели сервера.
2. **Списки** → «Добавить» → домены и IP по одной записи в строке ([docs/lists.md](docs/lists.md)).
3. **Основные настройки** → «Включить маршрутизацию».
4. «Сохранить и применить».
5. **Состояние** → «Проверка домена или IP»: домен из списка должен идти «через туннель».

Устройства «весь трафик через VPN» добавляются в разделе **Устройства** по MAC-адресу. Включать и выключать их удобнее кнопкой на странице **Состояние**.

Отключить IPv6 на роутере целиком (однократно): `sh /tmp/vpnroute/scripts/ipv6-disable.sh`.

Удаление: `sh /tmp/vpnroute/scripts/uninstall.sh` (с `--purge` — вместе с настройками).

## Командная строка на роутере

```
vpnroute status                  краткое состояние
vpnroute enable | disable        включить или выключить маршрутизацию
vpnroute apply                   применить настройки
vpnroute device list             устройства
vpnroute device TV toggle        переключить «весь трафик через VPN» (имя или MAC)
vpnroute check youtube.com       куда пойдёт трафик
vpnroute logs 100                журнал
vpnroute gen                     сгенерированная конфигурация Xray
vpnroute trace start <IP> [мин]  диагностика трафика устройства (см. docs/trace.md)
vpnroute list-add <список> <домен|IP>   добавить запись в список
```

## Структура репозитория

```
files/                          файлы, которые копируются в корень роутера
  etc/config/vpnroute           настройки по умолчанию (UCI)
  etc/init.d/vpnroute           служба: генерация, правила, запуск Xray
  etc/init.d/vpnroute-trace     служба сеанса диагностики (только по запросу)
  etc/hotplug.d/iface/          восстановление маршрута после перезапуска сети
  usr/bin/vpnroute              командная утилита
  usr/share/vpnroute/gen.uc     генератор конфигураций Xray, nftables, dnsmasq
  usr/share/vpnroute/status.uc  состояние в JSON для LuCI
  usr/share/vpnroute/trace.uc   сбор данных для диагностики трафика
  usr/share/luci/menu.d/        пункт меню LuCI
  usr/share/rpcd/acl.d/         права доступа LuCI
  www/luci-static/.../vpnroute/ страницы «Состояние», «Настройки», «Диагностика»
scripts/                        установка, удаление, отправка с ПК, отключение IPv6
docs/                           документация
```

Ссылки на серверы и резервные копии роутера в репозиторий не попадают: храните их в папке `local/` (она в `.gitignore`).
