# Прошивка Xiaomi AX3000T на OpenWrt 25.12

Так роутер был переведён с 24.10 на 25.12.6 (2026-10-24). В 25.12 менеджер пакетов opkg заменён на apk, поэтому прошивали без сохранения настроек и ставили всё заново.

## 1. Вариант разметки памяти

У AX3000T два варианта разметки, и образы для них **разные**. Посмотреть: LuCI → **Состояние → Обзор → Модель**, или `cat /tmp/sysinfo/board_name`.

| Модель в LuCI | `board_name` | Профиль в Firmware Selector |
|---|---|---|
| `Xiaomi Mi Router AX3000T` | `xiaomi,mi-router-ax3000t` | обычный |
| `Xiaomi Mi Router AX3000T (OpenWrt U-Boot layout)` | `xiaomi,mi-router-ax3000t-ubootmod` | с пометкой U-Boot layout |

Этот роутер: **стандартная разметка** (`xiaomi,mi-router-ax3000t`).

## 2. Образ

1. [firmware-selector.openwrt.org](https://firmware-selector.openwrt.org/) → `AX3000T` → свой вариант → нужная версия.
2. Скачать **SYSUPGRADE** (`…squashfs-sysupgrade.bin`).
3. Сверить контрольную сумму: `Get-FileHash .\файл.bin -Algorithm SHA256`.

## 3. Прошивка

1. Если роутер подключён к другой сети с адресами 192.168.1.x, **отсоединить его от неё** (кабель в LAN-порт). Чистая OpenWrt занимает 192.168.1.1 и включает раздачу адресов, что сломает ту сеть. ПК оставить подключённым к роутеру кабелем.
2. LuCI → **Система → Резервное копирование / Прошивка → Установить новую прошивку**.
3. **Снять «Сохранить настройки»**, подтвердить, подождать 3–5 минут.

## 4. Первая настройка

1. `http://192.168.1.1` → задать пароль root.
2. **Система → Администрирование → SSH-ключи** — добавить ключ ПК (`~/.ssh/id_ed25519.pub`).
3. **Сеть → Интерфейсы → lan → Изменить** → адрес `192.168.2.1` → «Сохранить и применить» → **«Применить без проверки»**, иначе через 90 секунд роутер вернёт старый адрес. Переподключить кабель на ПК.
4. Подключить провайдера (или вышестоящий роутер) в **WAN-порт**.
5. Настроить Wi-Fi.

## 5. Установка vpnroute

С ПК:

```powershell
.\scripts\deploy.ps1 -Router 192.168.2.1
```

Дальше — сервер и списки в LuCI, см. [README](../README.md).

## Если нужно сохранить старые настройки

Перед прошивкой: `sysupgrade -b /tmp/backup.tar.gz`, забрать архив на ПК в `local/` (папка не попадает в git): `scp -O root@<роутер>:/tmp/backup.tar.gz .\local\`. Из архива можно вручную перенести `network`, `wireless`, `dhcp`. Восстанавливать архив целиком на 25.12 не стоит: в нём останутся следы старых пакетов.
