# Списки доменов и адресов

Свои списки редактируются в LuCI: **Службы → VPN-маршрутизация → Настройки → Мои списки**. Встроенные списки описаны ниже.

## Правила записи

- Одна запись в строке. После `#` можно писать комментарий.
- Домен пишется без `www.` и `*.`: запись `example.com` покрывает `example.com` и **все** поддомены (`www.example.com`, `a.b.example.com`).
- Можно вставить ссылку целиком (`https://example.com/page`) — останется только домен.
- Кириллические домены вводятся в punycode: `xn--…`.
- IP-адреса: `1.2.3.4` или подсеть `1.2.3.0/24`.
- Список включается и выключается целиком галочкой «Включён».

После «Сохранить и применить» браузер и приложения могут какое-то время помнить старые адреса. Если сайт всё ещё идёт напрямую — перезапустите браузер или переподключите Wi-Fi на устройстве.

Проверить, куда пойдёт домен: страница **«Состояние» → «Проверка домена или IP»** или `vpnroute check <домен>` на роутере.

## Встроенные списки и свои списки

Списки бывают двух видов.

**Встроенные** входят в vpnroute и обновляются вместе с ним: YouTube, Claude, Discord, Meta (Facebook, Instagram, Quest), TikTok, Telegram, Chess.com и AliDNS для NekoBox. В LuCI их можно только выключить (**Настройки → Встроенные списки**), изменить нельзя. Списки, появившиеся в новой версии, включаются сами.

AliDNS (`223.5.5.5`) — DNS-сервер, который NekoBox по умолчанию использует как «прямой DNS», а провайдер его блокирует. Без этой записи NekoBox на телефоне в домашнем Wi-Fi выдаёт `dns_probe_finished_no_internet`.

**Свои списки** (**Настройки → Мои списки**) хранятся в настройках роутера, и обновление их не трогает. При установке создаётся пустой список «Мои адреса». Кнопка «+» в диагностике и `vpnroute list-add` не добавляют то, что уже идёт через VPN по встроенному списку.

Для разработчика: встроенные списки — файлы [files/usr/share/vpnroute/lists/*.list](../files/usr/share/vpnroute/lists). Одна запись в строке (домен, IP или подсеть), после `#` комментарий, первая строка `# name: Название`. Имя файла (латиница, цифры, `_`) — идентификатор списка, выключенный список хранится в настройках как `vpnroute.main.builtin_<id>='0'`. Новый файл попадёт на роутеры со следующей версией.

Локальные имена (`*.lan`, `*.local`, `*.home.arpa`) в списки не попадают: генератор их пропускает с предупреждением в журнале, иначе возникает петля DNS.

## Как подбирать домены

- Добавляйте **конкретные домены сервиса**, а не общие домены платформ. Например, `googleapis.com` и `googleusercontent.com` целиком используют почти все сервисы Google, и в туннель ушло бы много лишнего.
- Чтобы узнать, к каким доменам обращается приложение, включите на время `log_level` = `info` и смотрите `logread | grep dnsmasq` (или журнал на странице «Состояние»).

## Пример: YouTube

Проверено 2026-10-24: сайт, приложения и видео идут через туннель.

```
youtube.com              # сайт и приложения
youtu.be                 # короткие ссылки
googlevideo.com          # сами видеопотоки, самое важное
ytimg.com                # превью и обложки
ggpht.com                # аватары каналов
yt3.googleusercontent.com  # аватары и баннеры каналов
youtubei.googleapis.com  # внутренний интерфейс приложений YouTube
youtube.googleapis.com   # встроенные видео и API
jnn-pa.googleapis.com    # проверка приложения YouTube (Android, ТВ)
youtube-nocookie.com     # встроенные видео на других сайтах
youtubekids.com          # YouTube Детям
```

Проверка: `vpnroute check rr1---sn-abc.googlevideo.com` должна ответить «через туннель».
