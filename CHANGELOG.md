# История изменений

Формат версий: `MAJOR.MINOR.PATCH`. Роутер показывает разделы новее установленной версии, поэтому пишите их для владельца роутера, а не для разработчика.

## 1.0.0 — 2026-11-01

Первая версия с номером и обновлением из админки.

- Точечная маршрутизация через Xray (VLESS): домены через FakeDNS, IP и подсети, устройства «весь трафик через VPN».
- Устойчивая проверка серверов: одиночные заминки сервера не переключают трафик.
- Устройства за повторителями, подменяющими MAC, опознаются по IP из DHCP.
- Список «Основной» по умолчанию: YouTube, Claude, Discord, Meta, TikTok, Telegram и другие.
- Диагностика трафика устройства с добавлением найденного в список.
- Проверка обновлений раз в сутки и установка кнопкой на странице «Состояние».
