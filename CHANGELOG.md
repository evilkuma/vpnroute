# История изменений

Формат версий: `MAJOR.MINOR.PATCH`. Роутер показывает разделы новее установленной версии, поэтому пишите их для владельца роутера, а не для разработчика.

## 1.2.2 — 2026-11-11

- Исправлено: после обновления кнопкой из админки страница VPN-маршрутизации не открывалась (ошибка 403). Если вы уже обновились до 1.2.1 и видите эту ошибку, выполните на роутере по SSH `vpnroute update install`.

## 1.2.1 — 2026-11-11

- Новый встроенный список X (Twitter).
- Список Meta разделён на «Facebook и Messenger», «Instagram и Threads» и «Meta Quest»: их можно включать по отдельности. Добавлены недостающие домены: Messenger, Threads, короткие ссылки, картинки Instagram. Если список Meta был выключен, новые списки тоже выключены.

## 1.2.0 — 2026-11-11

- Новый интерфейс вместо стандартных страниц LuCI: одна страница с вкладками «Обзор», «Сайты и адреса», «Устройства», «Серверы», «Диагностика», «Настройки». Светлая и тёмная тема, версия для телефона.
- «Обзор» показывает схему: что идёт через VPN, что напрямую, работает ли маршрутизация.
- Сайты и адреса добавляются по одному через поле с подсказками: можно вставить ссылку, домен на русском, IP или подсеть, а панель предложит правильный вариант и предупредит, если сайт уже идёт через VPN. Можно вставить сразу много строк.
- Любую запись можно выключить, не удаляя, и подписать заметкой. Удаление можно отменить.
- Во вкладке «Устройства» видны все устройства сети: весь трафик через VPN включается одним переключателем.
- Сервер добавляется по ссылке, параметры видны сразу. Отпечаток браузера меняется списком.
- Изменения в списках, устройствах и серверах применяются сразу, без кнопки «Сохранить и применить».
- Поиск связанных доменов: после добавления сайта роутер открывает его через VPN и показывает, с каких ещё доменов сайт загружает файлы (картинки, скрипты, видео). Нужные отмечаются галочками и добавляются одной кнопкой. Тот же поиск — кнопкой с лупой у любого сайта в своём списке.
- Проверка «открывается ли без VPN»: кнопка у каждого сайта, в своих и встроенных списках. Роутер открывает сайт напрямую и через VPN и показывает, где обрывается прямое подключение: DNS провайдера, соединение, шифрование или загрузка. Видно, какие записи больше не нужны.
- Для поиска и проверки на роутер ставится пакет curl.

## 1.1.0 — 2026-11-01

- Встроенные списки: YouTube, Claude, Discord, Meta, TikTok, Telegram, Chess.com и AliDNS для NekoBox теперь обновляются вместе с vpnroute. В настройках их можно выключить по отдельности.
- Свои адреса хранятся в разделе «Мои списки», обновление их не трогает.
- Кнопка «+» в диагностике не добавляет то, что уже идёт через VPN.
- Установщик проверяет скрипты до копирования файлов: обновление с ошибкой не установится, роутер останется на рабочей версии.

## 1.0.0 — 2026-11-01

Первая версия с номером и обновлением из админки.

- Точечная маршрутизация через Xray (VLESS): домены через FakeDNS, IP и подсети, устройства «весь трафик через VPN».
- Устойчивая проверка серверов: одиночные заминки сервера не переключают трафик.
- Устройства за повторителями, подменяющими MAC, опознаются по IP из DHCP.
- Список «Основной» по умолчанию: YouTube, Claude, Discord, Meta, TikTok, Telegram и другие.
- Диагностика трафика устройства с добавлением найденного в список.
- Проверка обновлений раз в сутки и установка кнопкой на странице «Состояние».
